Telegram Notify gives agents a `telegram_notify` tool that sends a message to a Telegram group when something deserves your attention away from the screen: a finished report, a finding, or a question that blocks the work. Each message has a title, a short body, and an Open in bb button that takes you straight to the thread. It only sends. The plugin never reads replies from Telegram, so nothing said there can steer an agent.

You create a bot with @BotFather, paste its token into the plugin's settings, and list the chats agents may post to in the Chats section. Each chat has a name, a Telegram chat ID, and a note telling the agent when to use it. Find groups lists the groups the bot was added to, Check tests a chat on demand, and the first chat is the default. A chat the bot can't post to is marked with the reason, and the tool is offered only while at least one chat works.

A per-thread cooldown and an hourly cap across all threads keep a runaway agent from flooding your groups. The bot token stays on the bb server and never appears in logs, tool results or the frontend. Whatever an agent sends is readable by everyone in the target group, so the plugin tells agents to keep secrets out.
