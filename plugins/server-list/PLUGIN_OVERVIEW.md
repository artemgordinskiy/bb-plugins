Server List puts your self-hosted bb servers in a strip above the sidebar footer, marks the one you are on, and switches to another with one click. It needs no bb account and no getbb.app relay: you list the servers yourself in the plugin's settings, one per line as a name and a root URL.

In the desktop app, Server List switches through the app's own saved servers, matched by host. A listed server the desktop app has not saved yet is shown disabled with a hint to add its URL in the app's server settings first. In a browser or the mobile app, choosing a server opens that server's URL in the same window.

Settings are stored per bb server, so install the plugin on each server you switch between and give each the same list.
